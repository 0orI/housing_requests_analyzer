Housing Requests Analyzer

A beginner-friendly Python project for analyzing daily housing maintenance requests and tracking workload performance.

Features

* Calculate the total number of completed requests.
* Calculate the average number of requests per day.
* Identify the maximum and minimum daily workload.
* Determine the busiest day of the week.
* Count days when the daily target was achieved or missed.
* Calculate the percentage of days when the target was achieved.

Technologies

* Python 3
* Lists
* for loops
* Conditional statements (if/else)
* List indexing
* Basic arithmetic and formatted output

Example Output

Total requests: 70
Average requests per day: 11.67
Maximum daily requests: 19
Busiest day: Friday
Minimum daily requests: 6
Days with target achieved: 4
Days with target missed: 2
Target achievement rate: 66.67%

How to Run

1. Install Python 3.
2. Download requests_analyzer.py.
3. Open a terminal in the project directory.
4. Run:

python requests_analyzer.py

Project Purpose

This educational project was developed to practice Python fundamentals and basic data analysis using a housing maintenance workload scenario.

It demonstrates how to process structured data, calculate performance metrics, and generate a simple console report.
